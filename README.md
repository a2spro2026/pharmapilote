# PharmaPilote

Solution de gestion d’officine — connexion, tableau de bord, caisse et modules Achats / Ventes / Stock.

## Démo en ligne

**https://a2spro2026.github.io/pharmapilote/**

Identifiants de démo : `bilal` / `password` (statut Administrateur).

## Lancer en local

Ouvrir `index.html` via un serveur local (ex. port 5500), puis se connecter pour accéder au dashboard.
